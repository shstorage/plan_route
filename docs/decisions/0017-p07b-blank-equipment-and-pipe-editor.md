# ADR 0017 — P07b 빈 프로젝트·기기·배관 작성

날짜: 2026-10-12. 사용자 요청으로 예제에 의존하던 배치 편집을 보완한다.

## 기존 계약과 구현

Port는 `Equipment.ports`의 소유 관계를 갖는 배관 접속점이며 좌표와 외향 방향을 가진다.
배관의 양 끝은 Port ID를 참조한다. 경유점은 `Pipe.waypoints`에 저장되는 순서 있는
중간 조건이고, 기기 접속점이나 배관 끝을 대신하지 않는다.

기기 몸체는 기존 `Equipment.geometry_ref → Obstacle.id` 연결을 유지한다.
기기 종류는 탱크·펌프·열교환기·일반 기기를 제공하고, 몸체는 합성 AABB다.
새 스키마나 별도의 화면 픽셀·메시 정본을 추가하지 않는다. 좌표는 m, z 수직이다.
새 기기를 추가할 때 몸체와 외부 Port 두 개를 같은 JSON 변경으로 만든다.
기본 몸체 크기·배관 외경/보온 두께는 편집 시작값이며 실제 장비 사양이나 설계기준이 아니다.

빈 프로젝트는 20×12×6 m의 건물·1개 층·0.5 m 격자와 실행 설정만 가진다.
벽·Zone·기기·Port·배관·규칙은 없다. 백엔드와의 연결 없이도 화면에서 생성·편집할 수 있고,
검증·탐색·서버 저장에는 기존 FastAPI를 사용한다.

## 편집과 참조 보호

- 기기 몸체를 평행 이동하면 그 몸체를 참조하는 모든 기기의 Port를 같은 변위로 이동한다.
  Port 방향·배관 ID 연결·중간 경유점은 유지한다. Port 중 하나라도 건물 밖이면 변경 전체를 거부한다.
- 몸체 크기 변경은 Port 세계좌표를 유지한다. 이후 접속 위치를 사용자가 명시적으로 수정한다.
  기기 종류 변경도 몸체 크기·Port·연결을 자동으로 바꾸지 않는다.
- 소속 Port에 배관이 연결되어 있으면 기기 삭제를 차단한다. 사용자가 배관을 먼저 삭제하거나
  다른 Port로 연결을 바꿔야 한다. 기기 삭제는 소속 Port와 전용 몸체를 함께 지운다.
- 몸체가 규칙 대상이면 삭제를 차단한다. 공유 몸체는 다른 기기가 참조하는 동안 유지한다.
  몸체 단독 삭제도 차단해 `geometry_ref`가 깨지지 않도록 한다.
- 배관을 참조하는 규칙이 있으면 배관 삭제를 차단한다. 마지막 Port 단독 삭제는 기존 계약대로 막으며,
  기기 전체 삭제는 연결/규칙을 정리한 뒤 가능하다.
- 편집 결과는 기존 JSON 스냅샷 Undo/Redo에 포함된다. 기존 도면에서 빈 프로젝트를 시작한 것도 되돌릴 수 있다.
  삭제 후 선택 ID·배관 ID·강조 규칙을 존재하는 객체로 정리한다.
- 초기 예제 응답이 늦게 도착해 사용자가 만든 빈 프로젝트를 덮어쓰지 않도록 편집 개정 표식을 확인한다.

## 접속점과 충돌의 한계

기본 Port는 보수적 격자 차단에 들어가지 않도록 몸체 밖의 격자 중심에 놓는 **간략 외부 접속점**이다.
몸체 표면에 붙은 실제 노즐/허용 진입 터널/회전 연결은 모델링하지 않는다.
기기 몸체는 계속 일반 물리 장애물로 검사하며, 자신의 기기 몸체를 통과하는 충돌 예외를 만들지 않는다.
Port·몸체를 수정해 차단 위치나 잘못된 방향이 되면 기존 solver/validator가 실패 상태를 반환한다.
다른 기기/벽과 겹치는 장비 배치 자체의 독립 조립 검사나 다배관 공동 최적화는 별도 범위다.

## 재현·검수

UI: 빈 프로젝트 시작 → 기기 추가/종류 선택 → 두 위치 클릭 → 기기·배관 패널의 시작/도착 Port 선택
→ 배관 만들기 → JSON 검증 → 경로 계산 → 저장/불러오기. 몸체 이동·Port 수정·경유점 추가를 재실행한다.

`scripts/editor_blank_scenario.mjs`는 UI와 같은 편집 함수를 직접 호출해 예제 없이
두 기기·배관 생성·이동·삭제 JSON을 출력한다. Python 통합 테스트는 이 실제 출력으로
Pydantic/API 검증, A*/Dijkstra·독립 기하 검사, 서버 저장/재로드를 검수한다.
Node.js 22.18+가 없는 백엔드 전용 환경에서는 해당 두 통합 테스트가 이유를 남기고 skip한다.
Node 편집기 테스트는 경계/잘못된 참조/삭제 보호/종류 수정/Undo·Redo를,
3D 테스트는 동일 몸체·Port 좌표와 삭제 반영을 검사한다.

브라우저 이벤트·드래그·WebGL 수동 시연은 이번 자동 검수로 대체되지 않는다.
