# ADR 0019 — 작업 탭·보조 보기·다중 연결점 관리

날짜: 2026-10-12. 범위: 사용자 요청 P07d UI 보완 하나.

## 문제와 참고

배치할 객체와 배관 연결이 한 도구 그룹에 섞였고, 건물 설정·3D·프로젝트를 모두 펼치면 도면 아래로 화면이 길어졌다.
기기마다 여러 노즐을 표현할 연결점 관리도 선택한 기기 가까이에 있어야 한다.

[draw.io 공식 안내](https://www.drawio.com/docs/getting-started/)의 도형 그룹·선택에 따른 오른쪽 속성 패널과
[Onshape 공식 문서](https://cad.onshape.com/help/Content/Document/document_tabs.htm)의 작업 탭을 참고했다.
이 패턴을 본 도구에 적용한 설계 선택이며 CAD 제품의 기능·성능 동등성을 주장하지 않는다.

## 결정

- 선택, 배치(기기·벽·제약 구역), 배관 연결을 그룹과 코드 기반 SVG 아이콘으로 분리한다. 새 의존성은 없다.
- 계산 전 연결은 밝은 외곽의 짧은 점선·방향 화살표, 선택 시 배관 이름·미계산 배지로 표시한다.
  3D에도 미계산 연결을 표시한다. 실제 계산 성공 경로는 실선으로 구분하며 연결 표시를 검증 결과로 취급하지 않는다.
- 2D/3D/프로젝트/계산 결과를 탭으로 전환한다. 프로젝트 내부도 저장·불러오기/JSON 편집 탭으로 나눈다.
  선택 속성의 내부 ID·제약 상세, 작은 규칙 승인 항목은 확장을 유지한다.
- 반대 보기의 보조 창은 비모달 dialog로 열어 기준 도면을 계속 조작할 수 있게 한다.
  제목 드래그·모서리 크기 조절·닫기/Escape를 지원한다. 다른 브라우저 창을 생성하지 않는다.
- 건물·격자 설정은 모달 dialog로 편집한다. 실패는 모달 안에 표시하고 닫으면 포커스를 복원한다.
  모달과 숨겨진 2D 편집기에는 도면 삭제 단축키를 전달하지 않는다.
- 처음부터 빈 건물을 로컬에서 만든다. 서버 응답이 없어도 배치는 가능하고, 계산·저장·불러오기는 API를 사용한다.
  새 프로젝트는 기존 도면에 대한 Undo를 유지한다. 새로고침은 저장하지 않은 도면을 복원하지 않는다.
- 기기 속성/연결점 탭에서 개별 접속점을 추가·수정·삭제한다. 새 점은 세계좌표 X/Y/Z(m)와 방향을 명시한다.
  연결된 점은 삭제 금지, 기기에는 최소 하나의 Port가 필요하다. 삭제 보호와 규칙 참조 정책은 유지한다.
- 2D/3D/보조 창은 같은 프로젝트·선택·배관·결과를 사용한다. 3D에서도 선택 속성을 수정한다.
  후속 요청으로 3D 탭·보조 창에 배관 선택과 경로 계산 버튼·상태 요약을 추가했다.
  App의 기존 계산 작업과 busy 상태를 공유한다. 배관이 없거나 작업 중일 때 실행을 막는다.
  3D에서 도면 클릭이 필요한 연결/경유점/새 규칙 작업은 2D로 전환한다.

## 남은 범위

Port는 접속 표시용 점이며 실제 노즐 형상·기기 표면 터널 모델이 아니다. 추가 좌표는 사용자가 확인해야 한다.
기기 크기 변경은 Port 좌표를 자동 조정하지 않는다. 3D 탭을 새로 열면 기본 카메라로 시작한다.
전체 플랜트의 모든 층/규칙/드래그/WebGL 환경 회귀는 남아 있다. 합성 실험·탐색·승인·독립 검증 정책은 바꾸지 않아 벤치마크를 재실행하지 않았다.
