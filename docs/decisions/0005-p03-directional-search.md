# P03: 방향 인지형 3D 격자 탐색

- 날짜: 2026-10-11
- 상태: 채택

탐색 상태는 `(i, j, k, 진입 방향)`이며 방향은 `±x, ±y, ±z`와 시작 상태의
`NONE`이다. 같은 셀에 서로 다른 방향으로 도착하면 서로 다른 상태로 보관한다.
인접 6방향의 셀 중심 거리와 방향 전환 수에 각각 `length_per_m`,
`bend_per_event`를 곱해 비용을 계산한다. 두 가중치는 음수가 될 수 없다.

A* 휴리스틱은 목표 셀 중심까지 Manhattan 거리 × `length_per_m`이다.
직교 이동의 실제 중심 간 거리 합보다 클 수 없고 엘보 비용은 음수가 아니므로
허용 가능하다. Dijkstra 기준선은 같은 코드에서 휴리스틱만 0으로 둔다.
고정된 이웃 순서와 증가하는 heap 순번으로 동점 처리도 결정론적으로 한다.

시작 Port의 `orientation`이 첫 격자 이동 방향이고, 목표 Port에는 목표의
방향과 반대 방향으로 접근한다. 같은 셀에 두 Port가 있으면 격자 이동 없이
연결한다. 시작·목표 원좌표에서 셀 중심까지의 보정 구간 거리는 경로 길이와
비용에 포함한다. 엘보 수는 격자 이동 방향 변경만 센다. 보정 구간의 실제
연속 기하와 진입·출구 기하 제약은 P05 독립 Validator가 확인해야 한다.

P03은 규칙 없는 물리 격자만 탐색한다. 해당 Pipe에 승인된 규칙이 하나라도
있으면 `RULES_NOT_COMPILED`를 반환하여 규칙을 무시한 `SUCCESS`를 피한다.
미승인 규칙은 적용하지 않는다. 차단된 시작·끝 셀이나 스냅 허용치 초과는
`INVALID_INPUT`, 완전 탐색 뒤 경로 부재는 `NO_PATH`, 탐색 한도 때문에
결론을 못 내린 경우는 `SEARCH_LIMIT_REACHED`다.
