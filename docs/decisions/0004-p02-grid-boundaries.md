# P02: 3D 격자 경계와 보수적 셀 점유 정책

- 날짜: 2026-10-11
- 상태: 채택

건물 AABB 최소점을 격자 원점으로 사용한다. 해상도 `r`에서 셀 인덱스는
`floor((point - min) / r)`이며 건물 최소 경계는 포함하고 최대 경계는 제외한다.
셀 중심은 양끝의 중점이다. 마지막 셀이 부분 셀이면 건물 최대점에서 잘라
중심이 건물 밖으로 나오지 않도록 한다. 부동소수점 계산 오차가 내부 경계
인덱스를 바꾸지 않도록 셀 단위 `1e-9`의 허용오차를 둔다. 이 오차는 건물 밖
점을 안으로 들이지 않는다.

물리 마스크는 배관 외경 반경과 보온 두께의 합만큼 확장한 장애물 AABB와
셀 박스의 닫힌 교차를 기준으로 한다. 접촉도 충돌이며, 건물 내부 마스크는
셀 전체가 배관 반경을 포함해 건물 안에 있을 때만 허용한다. 이 방식은
L-infinity 팽창과 셀 단위 점유 때문에 실제 원형 배관보다 더 많은 셀을
막을 수 있다. 반대로 격자 셀만으로 연속 경로가 안전하다고 주장할 수 없으므로
후속 독립 Validator가 원본 연속 기하에서 최종 검증해야 한다.

Zone은 접촉 셀을 별도 마스크에 기록한다. 물리 장애물 마스크와 합치지 않는다.
`KEEP_OUT` 승인 상태 및 규칙별 clearance는 P04 Compiler가 처리한다.
배관 식별자가 존재하지 않으면 voxelizer는 명시적으로 실패한다.
