# ADR 0018 — P07c 도면 중심 편집과 선택 속성

날짜: 2026-10-12. 사용자 승인 제안: 도면에서 객체를 선택하고 필요한 속성만 수정한다.

## 변경

큰 기기·배관 구성 패널을 제거했다. 기본 도구는 선택·기기 추가·배관 연결·벽 추가·제약 구역 추가다.
계산할 배관 선택과 경로 계산 버튼은 도면 위에 유지한다. 화면 이동·층·스냅·건물/격자 설정은 보조 도구다.
기기를 클릭하면 종류·위치·크기·삭제가, 연결점에는 소속/좌표/방향이, 배관에는 양 끝 기기·단면·경유점·삭제가 나온다.
내부 ID·추가 마진·연결점 목록·규칙/승인 관리·JSON/상세 결과·3D는 필요한 경우 펼친다.
기기·Port·배관 생성/삭제의 P07b 참조 보호와 Undo/Redo를 유지한다.

Port의 화면 이름은 연결점, Zone은 제약 구역이다. 펌프 1/연결점 2/배관 1 같은 이름은
JSON에서 계산하는 표시 이름이며, 저장 ID나 스키마를 바꾸지 않는다.
빈 도면/기존 예제를 모두 편집하며 동일 EngineeringProject가 저장·검증·탐색·2D/3D의 정본이다.

## 두 번 클릭과 경로 구분

배관 연결 도구에서 첫 클릭은 시작 연결점만 기억하고 JSON을 바꾸지 않는다.
두 번째 유효 클릭으로 기존 createPipe 함수를 통해 배관을 생성한다.
동일 Port·없는 참조·삭제된 시작점은 거부하며 재선택/취소할 수 있다. 선택 도구·Esc로 연결을 취소한다.
연결 표시를 클릭하면 해당 배관을 선택하고 속성창에서 수정한다.

계산 전의 점선은 Port와 순서 경유점을 잇는 **연결 관계 표시**다. 장애물을 통과할 수 있고
독립 기하 검증이 된 경로가 아니다. solver/validator 입력으로 재사용하거나 저장 경로로 간주하지 않는다.
선택 배관의 성공 계산 후에는 점선을 숨기고 실제 경로를 실선으로 표시한다.
다른 배관은 점선 연결 표시를 유지한다. 계산된 선을 다시 클릭해도 같은 배관의 계산 결과는 지우지 않는다.
기하·단면·규칙·연결을 수정하면 기존 결과를 무효화하며 재계산해야 한다.
실패/미승인/검증 위반 응답과 승인 절차는 기존 계약을 유지한다.

## 검수

직접 실행:

```powershell
uv run pytest -q
uv run ruff check .
cd frontend
npm run test:editor
npm run test:viewer
npm run lint
npm run build
```

Python 214/editor 32/viewer 11 통과, Ruff/lint/build 통과.
기존 Starlette 폐기 예정 경고와 Vite 500 kB 초과 청크 경고는 유지한다.
Node 편집 테스트는 두 번 클릭·동일/잘못된 참조·연결 표시/경유점·배관 선택의 층·삭제·표시 ID 불변성을 검사한다.
Python 통합 테스트도 실제 프런트의 pickConnection 출력으로 검증·탐색·저장/로드를 수행한다.

실제 브라우저 검수는 새 의존성 없이 설치된 Edge의 headless CDP와 Node 내장 WebSocket을 사용한다.
먼저 Vite :5173/FastAPI :8000을 실행하고 루트에서 `node scripts/check_editor_ui.mjs`를 실행한다.
브라우저 실행 파일은 `EDITOR_TEST_BROWSER`, 프런트 주소는 `EDITOR_TEST_URL`로 지정할 수 있다.
기본 API 주소/CORS는 기존 로컬 실행 설정을 따른다. 각 실행은 새 프로필을 사용하고 종료한다.

최종 결과: `data/ui_checks/p07c-1791796852044/result.json`.
빈 상태에서 기기 두 개 배치, native 캔버스 클릭 두 번 연결, 같은 점 재클릭 거부,
**실제 FastAPI 계산**, 계산된 선 선택 시 결과 유지, 접힌 3D 열기/WebGL 렌더,
속성 위치 수정과 Port 동반 이동, 연결 기기 삭제 보호, 배관 삭제/실행 취소,
390 px 화면의 가로 넘침 검사를 통과했다. 미처리 브라우저 오류 0건.
연결/계산/3D/모바일 캡처를 직접 확인했다. 결과·프로필·이미지는 Git 제외 대상이다.

## 남은 범위

이는 작은 합성 흐름의 브라우저 검수다. 전체 플랜트 장면의 층간 이동·모든 규칙 승인·드래그/리사이즈·
저장/로드를 브라우저에서 모두 재검수한 것은 아니다. 여러 배관을 동시에 계산·충돌 조정하지 않는다.
JSON이나 내부 ID를 감추는 것은 표시 방식만 바꾸며 규칙 승인/기하 검증을 생략하지 않는다.
