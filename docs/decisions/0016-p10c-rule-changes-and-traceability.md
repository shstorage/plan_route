# ADR 0016 — P10C 규칙 변경 대조와 추적성 검수

날짜: 2026-10-12. 범위: 합성 단일 배관 장면의 규칙 변경 실험.

## 문제와 결정

`applied_rule_ids`는 실행에 적용한 규칙 목록이다. 목록에 있다는 사실만으로
경로 변경의 원인이나 규칙의 독립적인 영향 크기를 입증하지 않는다. 동일한 물리 입력·격자·알고리즘을
고정하고 규칙만 변경한 대조 입력을 저장한다. 기존 P10A/B 실행 보존 체계를 사용하며
P10B 알고리즘 시간 비교와 별도의 `suite: changes`로 분석한다.

## 사전 고정 입력

`benchmarks/changes.json`: 개발 시드 11/23/42/71/101, 평가 211/307,
1 m·0.5 m 격자, A*·Dijkstra, 각 3회. 시드는 합성 Zone 높이(3.1~4.8 m)를 결정한다.
같은 시드의 물리 공간·Port·배관·비용·검색 한도는 모든 규칙 대조에서 동일하다.
두 번째 Zone은 모든 입력에 있지만 봉쇄 규칙을 추가할 때만 차단 대상이 된다.

장면당 12개 입력:

1. 규칙 없는 기준선.
2. `RULE-KEEP`: Zone KEEP_OUT 추가.
3. `RULE-CLEAR`: 같은 Zone의 MIN_CLEARANCE 0.25 m 추가.
4. 이격을 1.25 m로 수정하고 개정·승인 연결을 갱신.
5. 규칙의 출처 문서 개정·근거만 수정하고 재승인. 실행 수치는 동일.
6. 같은 Zone의 중복 KEEP_OUT(`RULE-DUPLICATE`) 추가.
7. 전체 규칙에서 `RULE-KEEP`만 제거.
8. 전체 규칙에서 `RULE-CLEAR`만 제거.
9. 전체 규칙에서 `RULE-DUPLICATE`만 제거.
10. 기준선에 Y/Z 전체를 막는 `RULE-SEAL` 추가.
11. 승인 규칙을 draft로 바꾼 실행 차단 진단.
12. 승인 내용 해시를 갱신하지 않고 이격을 바꾼 실행 차단 진단.

총 7개 물리 장면, 해상도별 대조 입력 168개, 실행 1,008회다. 기준선의 직선과
제약 장면의 떨어진 직교 우회 경로를 탐색 전에 지정한다. 원본 AABB에 대한 독립 축 평행
거리 계산과 소형 명시적 격자 기준 계산으로 입력·비용 계약을 검사한다.
600셀 초과의 연결된 기준 그래프는 최적비용 `NOT_COMPUTED`; 분리 증명은 계속 유지한다.
이는 원래 연속공간의 최적해 증명이 아니다.

승인 데이터는 고정된 시각·이름의 **합성 fixture 선언**이다. 실제 사용자의 승인을 자동으로
대신하는 기능이 아니며 생산용 승인 API의 인증 수준도 바꾸지 않는다.

## 측정과 근거 연결

- 반복마다 원본 입력·해시·보고서·개정/승인을 기존 배치 폴더에 저장한다.
- 같은 알고리즘의 전후 입력을 대조한다. 성공한 `EXACT_GRID` 쌍만 비용·길이·굽힘 차이를 계산한다.
  `NO_PATH`, 예산 초과, 미승인, 휴리스틱 결과에는 유한 비용 차이를 만들지 않는다.
- 경로 좌표 변화와 양쪽 꼭짓점에서 상대 꺾은선까지의 최대 최단거리를 측정한다.
  이 표본 거리는 연속 Hausdorff 거리의 정확한 계산이 아니다.
- 전체 규칙 마스크 합집합의 추가/제거 셀 집합을 비교한다. 정렬된 규칙 처리 순서의
  `newly_blocked_cells_count`와 구분하며 이 값도 물리 공간의 인과 크기로 해석하지 않는다.
- 변경 전 경로를 변경 후 규칙으로 검증하고, 변경 후 경로를 변경 전 규칙으로 검증한다.
  따라서 규칙 제거로 얻은 경로가 원래 이격 요구를 위반하는 구간도 보존한다.
- 규칙 정의·내용 해시·개정·승인·출처·대상·배관과 compiler 영향 기록의 연결을 대조한다.
  독립 validator 위반에는 규칙·원문 출처·대상 객체·원래 선분 번호·양 끝 좌표를 연결한다.
  누락된 ID/출처/객체/구간은 연결 실패다. 연결 0개인 검사는 분모 없는 별도 건수다.
  이 family의 규칙 위반 구간은 축 평행이므로 원본 AABB 거리식을 별도로 계산해
  선분 번호가 범위 안에 있어도 잘못 연결된 구간·측정거리·요구거리·위반 종류를 거부한다.
  대각선 구간의 독립 거리 검수로 일반화하지 않는다.
- 직선이 Zone을 관통하는 추가 규칙 반례는 알려진 규칙 위반 검출을 요구한다.
  출처 수정과 중복 규칙/중복 KEEP_OUT 제거는 중립 대조다. 강화·제거 비용의 단조성과
  실행 차단을 검사하고, 누락/중복 반복·비결정적 결과는 분석 실패로 남긴다.

반복은 장면별 한 대조로 묶고 시간은 중앙값을 저장한다. 규칙·알고리즘·split·해상도별 비용 차이는
시드 cluster bootstrap 2,000회로 기술 통계를 만든다. 시드 1개에는 신뢰구간을 만들지 않는다.
평가 시드가 2개뿐이며 하나의 Zone family이므로 신뢰구간을 실무 일반화 근거로 쓰지 않는다.

## 산출물과 재현

```powershell
uv run python scripts/run_benchmark.py --config benchmarks/changes.json
```

- `change_report.md`: 같은 알고리즘의 규칙 변경 요약·통계·한계.
- `change_metrics.csv`: 전후 상태·비용·길이·굽힘·형상·마스크·반복 중앙값.
- `change_comparisons.json`: 입력·실행 ID 연결, 전후 규칙 정의, 경로 재검증 및 위반 근거.
- `traceability_audit.json`: 각 실행의 승인/출처/대상 연결 검수.
- `change_statistics.json`: 비교 분모·연결 분모·실패·시드 단위 통계.
- `figures/rule_change_objective.png` / `.pdf`: 평가 A* 장면의 비용 변화 그림.
- 기존 `source.zip`, `environment.json`, `execution_plan.json`, `runs.csv`, 실행별 원본/결과도 유지.

## 주장 한계

이 실험은 승인 규칙의 구조화·내용 연결·독립 기하 검증과 대조 실행을 함께 보존하는 연구 흐름의
구현 근거다. A*의 새로움, 다른 연구보다 우월한 성능, 외부 법규의 완전성,
로그인 기반 승인·변조 방지, 실제 배관 설계 적합성을 입증하지 않는다.
차별성 문장은 선행연구의 실제 방법과 지표를 같은 범위로 대조해 별도로 확정해야 한다.
브라우저/WebGL 수동 시연, 실제 관통부·Soft Zone·다배관·CAD는 이번 Phase에 포함하지 않는다.
